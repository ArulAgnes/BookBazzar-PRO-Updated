# 🌟 About the Project

**BookBazzar PRO** is a complete Online Book Store Management System developed using **PHP, MySQL, HTML, CSS, JavaScript, Bootstrap, and PHPMailer**.

The system allows users to browse books, search by category or publisher, add books to the cart, complete purchases, and receive email notifications. Administrators can manage books, approve uploads, handle categories, publishers, and purchase records through a dedicated dashboard.

# ⚙ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/BookBazzar-PRO-Updated.git
```

Move the project to:

```text
xampp/htdocs/
```

Import:

```text
database/bookbazzar.sql
```

Start Apache and MySQL in XAMPP.

Open:

```text
http://localhost/BookBazzar
```
